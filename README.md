# 基层班团学生干部考核系统

<img src="assets/lcq-logo.png" width="88" height="88" alt="LCQ 标志" />

**最新版本：v2026.10.11.1** · 更新日期：2026 年 10 月 11 日

面向基层班团学生干部信息填报、审核评定和汇总管理的 Web 系统，涵盖班级填报、年级审核、团委汇总三个环节。系统通过加密上报文件传递数据，在本地保存填报与审核记录，减少重复录入和手工汇总。

系统按书院、年级和班级组织数据，将人员信息、任职关系、考核等级与分数纳入统一的工作流程。班级负责基础信息填报，年级负责审核与评定，团委负责汇总统计及表格生成。各环节通过文件导入衔接，并结合数据校验、版本比较和操作确认，减少重复上报与误操作对已有记录的影响。

[在线使用](https://krc.callmek.cn/) · [使用说明](docs/USAGE.md) · [完整更新记录](CHANGELOG.md) · [项目支持与致谢](https://krc.callmek.cn/thanks.html?from=showcase)

## 核心功能

### 人员信息与任职管理

统一录入姓名、学号、联系电话、职务和备注，检查必填信息、重复学号与职务覆盖情况。团支部书记须兼任班长，纪律委员须兼任副班长，系统按此规则联动任职信息，并支持额外兼任。职务已由他人担任时，可通过任职调整窗口交换或重新分配，无需删除人员后重新录入。人员展示和表格导出采用一致的职务排序，团支部书记（班长）、纪律委员（副班长）优先排列。

### 审核评定与多选筛选

年级端支持按年级、班级、职务和考核等级多选筛选；团委端还支持按书院及不符合学生干部要求的情况筛选。点击“应用筛选”后条件生效，“取消”放弃本次选择，“清除筛选”恢复该项的全部范围。审核可逐人进行，也可对筛选结果批量评定；人员修改及批量评定均提供确认环节。

系统按书院、年级分别校验名额，以对应范围内已录入的学生干部人数为基数：优秀人数上限为基数的 30%，优秀与良好合计人数上限为基数的 70%，两个上限均向下取整。评定时同时检查职务对应的分数范围及不符合学生干部要求的情况，导出前再次核对数据。

### 多文件导入与版本比较

支持分次追加文件、查看具体文件名、逐项移除和按内容去重，同名但内容不同的文件分别保留在待处理列表中。再次导入同一范围时，系统比较当前记录、上次导入的来源记录与新文件，列出人员新增、移除和信息修改。相同上报内容跳过；本端修改与新上报内容冲突时，默认保留本端记录，也可逐项选择采用上报内容，确认后再更新。文件验证、导入状态及处理结果逐项展示。

重复学号处理在三端保持一致：班级录入、年级审核和团委汇总均列出冲突人员及其所属范围，可在核对窗口修正后继续。导入时还标明来源文件；已有人员与本次导入内容均可修正，所有冲突消除后才保存。学号纠错不改变考核等级、分数或原始来源记录，也不会回写源文件。

### 进度统计与工作衔接

年级端、团委端的数据大屏集中展示已上报与应上报班级数、学生干部人数、待评定人数、名额使用情况及工作区保存状态。团委端按书院、年级分组列出未收到上报文件的班级，通联表覆盖统计区分本学期与历史学期数据。可通过相应统计入口进入工作页面或筛选结果；导出后数据发生变化时，系统提示重新导出。

### 考核汇总与表格导出

团委端根据年级上报文件生成考核结果汇总表，也可直接汇集班级上报文件生成基层班团学生干部通联表。Excel 表格统一人员顺序、标题与正文格式，阿拉伯数字使用 Times New Roman 字体；两字中文姓名在导出时于两字之间加入两个空格，不改变原始记录。表格保留配置中的书院、年级和班级结构，便于核对与归档。

通联表导入时，若文件内部或与已有记录存在重复学号，可在冲突窗口核对具体人员、所属范围和来源文件，并修改姓名、学号、电话及备注。全部通过校验后才保存本次导入，取消则保留原数据。已导入人员可通过编辑窗口维护基本信息与职务；修改仅作用于通联工作区，不回写原始上报文件或考核汇总。明细支持按书院、年级、班级多选筛选，导出仍采用完整通联数据。

### 学期配置与历史查阅

管理员可维护学期、书院、年级、班级配置，以及填报码和各端密钥。考核工作区按学期隔离，同学期重置登录凭据时保留数据密钥，以便继续使用该学期的上报文件与工作区。通联表支持经确认的跨学期导入；历史上报文件可使用已留存的解密信息只读查看，不并入当前考核记录。

## 工作流程

1. **准备学期**：管理员核对学期及书院、年级、班级范围，发布系统配置，并向对应负责人下发填报码与密钥文件。
2. **班级填报**：填报人选择所属班级，录入学生干部，核对人员信息、任职关系与职务覆盖，导出班级上报文件交由年级审核。
3. **年级审核**：导入各班上报文件，审核人员信息、填写相关情况说明并完成考核评定，核对名额使用情况与分数后导出年级上报文件。
4. **团委汇总**：汇集年级上报文件，核对上报进度、人员明细和名额使用情况后生成考核结果汇总表；通联表由班级上报文件汇集生成。

班级上报与年级上报均使用 `.lcq` 加密文件流转，考核结果汇总表和通联表以 Excel 格式导出。文件保护依靠加密与校验，而不是后缀本身。

## 数据存储与保护

- 人员信息与考核数据在本机浏览器中处理，保存在浏览器草稿、授权工作文件夹或导出文件中；业务数据不随系统配置上传至 GitHub。
- GitHub 用于代码和公开系统配置的版本管理，网站由 Vercel 托管。各端通过文件交换衔接，不进行多人实时同步编辑。
- 班级草稿保存在浏览器中，年级和团委工作区保存在授权的本地文件夹中。请妥善备份数据及密钥，清理浏览器数据或丢失文件可能影响恢复。
- 换域名、换浏览器或换电脑不会自动迁移草稿、登录状态与文件夹授权。同学期重置登录凭据与跨学期数据处理的规则见 [使用说明](docs/USAGE.md)。
- 网页资源缓存完成后可在一定条件下离线使用；离线期间无法即时获知新的学期配置或凭据撤销，恢复联网后应刷新核对。
- 历史文件解密需要保留对应的解密信息，系统不能恢复已经丢失的历史私钥。
